# Final-Individual-Project
Repository containing the final CAD files used in the fabrication of the phantom for this Individual Project.
**In this repository you will find:**
1. Initial Benchmark Phantom model (as seen in Akor et al. paper, https://doi.org/10.3390/s25164974)
2. PittBrains3D model (https://github.com/PittBrains3D/PittBrains3D---Digital-3D-Models-for-Neuroanatomy-Instruction/tree/main)
3. Adapted Skull model
4. Finalised Brain Agar Mould
